PyDFile

Local desktop PDF tool for merging, splitting, organizing, converting, compressing, protecting, unlocking, and extracting text from PDFs.

Python CustomTkinter PyMuPDF pikepdf PyInstaller

About the project

PyDFile is a desktop PDF tool built in Python for everyday document tasks. It runs locally on the user's computer without requiring an internet connection, so files do not need to be uploaded to a server or passed through a web service. The app focuses on practical workflows such as merging PDFs, splitting page ranges, organizing pages, adding watermarks, adding page numbers, compressing files, protecting and unlocking PDFs, converting between PDFs and images, and extracting text.

The interface is built with CustomTkinter and organizes each workflow into its own tool page. The codebase separates PDF and image operations into a core layer, reusable interface pieces into UI modules, and shared constants and file helpers into utilities, keeping the project easy to extend as more document tools are added.
